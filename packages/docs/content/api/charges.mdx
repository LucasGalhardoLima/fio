# Charges

## POST /v1/charges

Cria uma cobrança PIX avulsa.

```json title="Request"
{
  "customer_id": "cus_abc123",
  "amount": 15000,
  "expires_in": 3600,
  "description": "Pagamento avulso",
  "metadata": {}
}
```

`expires_in`: segundos (default 3600, max 86400).

```json title="Response (201)"
{
  "id": "chg_def456",
  "customer_id": "cus_abc123",
  "amount": 15000,
  "status": "pending",
  "payment_method_type": "pix",
  "pix_qr_code": "00020101021226870014br.gov.bcb.pix...",
  "pix_qr_code_image": "data:image/png;base64,...",
  "pix_copy_paste": "00020101021226870014br.gov.bcb.pix...",
  "expires_at": "2026-03-04T11:00:00Z",
  "created_at": "2026-03-04T10:00:00Z"
}
```

Use o header `Idempotency-Key` para evitar cobranças duplicadas.

## GET /v1/charges/:id

Retorna uma cobrança pelo ID.

## POST /v1/charges/:id/refund

Processa reembolso total ou parcial.

```json title="Request"
{
  "amount": 5000
}
```

Omita `amount` para reembolso total. Retorna 422 se a cobrança não estiver paga.

## GET /v1/charges

Lista cobranças com paginação.

**Query params**: `starting_after`, `limit`, `status`, `customer_id`.
